# PersonalVault

A secure Android personal vault app built with Kotlin + Jetpack Compose.

## Features
- Encrypted local storage with SQLCipher
- Google Sign-In authentication
- Expense tracking with budgets, insights, and reports
- SMS transaction auto-detection and approval
- Health tracking (workouts, meals, profile)
- Family sharing with Firestore sync
- Push notification reminders
- Biometric lock
- Photo/file attachments

## Tech Stack
- Kotlin 2.0, Jetpack Compose, Material 3
- Room + SQLCipher for encrypted database
- Firebase Auth + Firestore
- WorkManager for reliable notifications
- MVVM architecture
